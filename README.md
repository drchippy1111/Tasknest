Tasknest is an innovative task management and productivity app designed to help individuals and teams organize, track, and complete tasks efficiently. Built with HTML, CSS, and JavaScript, Tasknest also includes advanced features such as financial planning, AI business plan writing, and ad posting integration.

---

Features

- *Task Management:* Create, edit, and delete tasks with a Trello-style board.  
- *Collaboration Hub:* Share tasks, projects, and updates with team members.  
- *Financial Planning Tools:* Track balance sheets, budgets, and financial goals.  
- *AI Business Plan Writer:* Generate structured business plans for startups or projects.  
- *Ad Posting Integration:* Create and manage ads for digital campaigns.  
- *User Authentication:* Sign up and log in using Gmail and phone number.  
- *Responsive Design:* Works seamlessly on desktop and mobile devices.  
- *Offline Support:* Progressive Web App (PWA) enabled for offline use.  

---

Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Tasknest.git
```

2. Navigate into the project directory:

```bash
cd Tasknest
```
Open `index.html` in your preferred browser to view the app locally.

---

Technologies Used

- *Frontend:* HTML, CSS, JavaScript  
- *Backend (optional):* Firebase for authentication, storage, and database  
- *PWA Support:* Manifest.json and service worker for offline capabilities  

---

Usage

1. Open `index.html` in your browser.  
2. Register using Gmail or phone number.  
3. Start creating tasks and explore features like AI business plan writer, balance sheet, and ad posting.  
4. Collaborate with team members via the collaboration hub.
